## Projects

### 📊 Excel Sales Report Automation Tool

Excel VBAを使用した売上集計自動化ツールです。

ボタン1つで売上データから担当者別・商品別の集計を行い、グラフまで自動生成します。

**主な機能**
- 担当者別売上集計
- 商品別売上集計
- 売上金額の自動計算
- グラフ自動生成
- 入力チェック
- エラー処理

➡️ [View Project](https://github.com/ktautomation-dev/excel-sales-report)

### 🔄 CSV Merge Tool

Pythonを使用して複数のCSVファイルを安全に1つへ結合するツールです。

列構成を自動チェックし、異なる形式のCSVが含まれている場合は処理を停止します。

**主な機能**
- 複数CSVの一括結合
- ヘッダー重複防止
- 列構成チェック
- 空CSVのスキップ
- エラー発生時の安全停止
- 日時付き出力ファイル生成
- 処理件数・処理時間の表示

➡️ [View Project](https://github.com/ktautomation-dev/csv-merge-tool)
